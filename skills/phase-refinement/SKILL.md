# Phase Refinement

## Resumo

Refina uma demanda antes do plano técnico, removendo ambiguidades e consolidando requisitos, restrições, riscos e critérios de aceite.

## Quando usar

- Durante `DOR`
- Durante `SPEC`
- Quando a intenção da tarefa ainda está vaga
- Quando faltam critérios de aceite testáveis

## O que esta skill faz

1. Identifica lacunas de contexto
2. Converte pedidos vagos em requisitos claros
3. Separa requisito funcional, não funcional e fora de escopo
4. Expõe riscos e dependências cedo
5. Produz insumos melhores para `spec.md`

## Saída esperada

- resumo do problema
- lista de requisitos funcionais
- lista de requisitos não funcionais
- critérios de aceite testáveis
- principais riscos e dúvidas remanescentes

## Regra operacional

Se ainda houver ambiguidade material após o refinamento, não avançar para `PLAN` como se a tarefa estivesse pronta.
